# 概念学习资料生成 Skill

## 1. 适用场景
适用于快速拆解和学习 AI 与软件工程中的新技术概念，自动生成结构统一、具备深度理解与参考来源的个人学习资料。

## 2. 输入信息
- 目标概念名称（如 Agent、LLM Context、Skill 等）
- 可选扩展要求（如特定行业视角或重点关注维度）

## 3. 处理流程
1. 概念定义：给出通俗易懂的直觉解释（避免死记硬背）。
2. 核心机制：拆解底层原理或关键构成要素。
3. 典型应用场景：列举真实工程/业务中的 1-2 个应用场景。
4. 易混淆点与使用边界：对比相似概念，划定“能做”与“不能做”的边界。
5. 可核查参考来源：附带官方权威文档链接。

## 4. 输出规范
- 必须为 Markdown (.md) 格式。
- 必须完整包含：个人解释、核心机制、应用场景、易混淆点与边界、资料来源五个标准章节。

## 5. 自检要求
- [ ] 是否使用通俗语言，避免纯术语堆砌？
- [ ] 是否清晰划定了概念的适用边界与局限？
- [ ] 参考链接是否为真实有效的官方权威来源？
