# 概念关系说明：Agent、LLM Context 与 Skill 的协同机制

在现代 AI 应用架构中，Agent、Context 与 Skill 构成了“认知-决策-执行”的完整闭环：

- **Agent（智能体/执行主体）**：相当于调度中枢或“项目经理”，具备感知、目标拆解、工具调用与自主决策能力。
- **LLM Context（上下文/工作记忆）**：相当于“当前案桌上的资料”，定义了 Agent 在当次决策中所能看到的背景、约束与历史对话。
- **Skill（技能/标准规范）**：相当于“SOP 操作手册”，将特定任务的流程与标准模块化封装。
